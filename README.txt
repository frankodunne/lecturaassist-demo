LECTURAASSIST — INTERACTIVE STUDENT DEMO v0.1

QUICK START (WINDOWS)
1. Unzip the supplied ZIP file to a folder.
2. Double-click index.html.
3. The demo opens in your default web browser (Chrome or Edge recommended).
4. No installation, login, internet connection or API key is required.

DEMONSTRATION (3–5 MINUTES)
1. Show the first lecture slide. Click 'Show original slide'.
2. Click 'Show personalised view'.
3. Select the 'Reading comfort' profile and show the changed layout.
4. Adjust font size, colour theme, highlighting, spacing and simpler wording.
5. Click 'Play captions' to show simulated lecturer captions.
6. Navigate through the three prepared lecture slides.
7. Select the 'Caption focused' profile to demonstrate different preferences.
8. Open Transcript and Notes. Optionally try Read slide aloud.

IMPORTANT LIMITATIONS
- Captions are simulated using prewritten text; no live audio is processed.
- Simplified slide content is prepared in advance, not generated by AI.
- Lecture and lecturer are fictional examples.
- No data is uploaded to a server. Notes are temporary and disappear on refresh.
- The demo does not prove educational outcomes or establish a clinically validated dyslexia setting.

OPTIONAL HOSTING
This is a static website: upload index.html to any static host such as GitHub Pages or Netlify.
Avoid uploading real student data or lecture materials without permission.
